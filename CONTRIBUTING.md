# Contributing

Honest version: **this is a personal app.** One person uses it, and the repository is
public because the code is worth showing, not because the project is looking for
contributors.

Issues are welcome — a bug report or a genuinely good idea is useful to me. Pull requests
may not be merged, and it would be unfair to let you write one without saying so first. If
you want a change badly enough, forking is the reasonable path; the licence is Apache-2.0
and you owe me nothing.

If you do open a PR anyway:

- Conventional commits, one logical change each.
- `./gradlew check` must pass, including the manifest permission check.
- No new dependency without a line in the README explaining why it earns its place.
- No `TODO`, no commented-out code, no unused resources.
